## Editorial priorities

1. Keep the validated ten-occupation primary employment/real-wage comparison and geographic/fixed-weight sensitivity figures as the principal manuscript displays.
2. Add the Phase 16 coverage chart, selected four-occupation trajectories, and baseline-size sensitivity as supplementary figures after verifying the exact underlying data and captions.
3. The primary common-sample 212 metros, stable county-membership set of 282, and five-year occupation-specific coverage are not interchangeable with the expanded 2021/2025 endpoint sample counts.
4. Avoid redundant figures if they present identical findings; include each chart for a distinct research question.
